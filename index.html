Copilot Code Review

Find issues Verify findings Human review

It can miss bugs or flag non-issues. Keep tests, code scanning, and human review in the loop.

Choose a Review Effort

On GitHub, set the effort under Reviewers before requesting a Copilot review.

  • Lite: Targeted feedback on obvious issues.
  • Balanced: Deeper analysis for complex changes.
  • Max: Most scrutiny for critical changes.
  • Adaptive (preview): Copilot picks based on PR complexity and risk.

Working With Agents

Security & Privacy

Before you delegate, decide what the agent can see, what it can do, and how you’ll verify the result.

Share only what’s needed

  • Use approved tools and data.
  • Keep secrets and unapproved sensitive data out of prompts and attachments.

Limit what it can do

  • Grant only the repo and tool access the task needs.
  • Check what a command or tool call will read or change before approving.

Verify before you merge

  • Read the diff and check it against the task.
  • Keep required tests, security scans, and human review in place.

For GitHub work, follow internal data-handling policy. GitHub Docs: Responsible use of agents.
